## GO Reloaded :
Go reloaded is a Go program that processes text files and applies transformation such as : uppercase, lowercase, hexadecimal and binary conversions. After processing the text, the program writes the modified result into output file.

## Installation 
clone the repository : 

Navigate into the project directory :
cd  go-reloaded
Make sure GO is installed :
go version

## usage 
Run the program using:
go run . sample.txt  result.txt 

### features 
- converts words to uppercase '(up)'
- converts words to lowercase '(low)'
- capitalize words '(cap)'
- convers hexadecimal numbers '(hex)'
- converts binary numbers '(bin)'
